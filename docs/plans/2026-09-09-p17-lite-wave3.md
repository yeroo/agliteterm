## Deliberate lite boundaries

Each library window is a separate process/pipe. Quick is one per process; no shared
UI broker is introduced. Explicit window selectors resolve the addressed instance
or refuse, never silently redirect. Picker polling stays on the originating pipe;
eight completed answers are retained there, and process exit ends them. Full-app
cross-window closed-owner retention does not apply. Native GDI/control accessibility
is not terminal UIA parity. Shell hints and hosted write acknowledgements are not
proof of prompt readiness or command execution. Existing whole-file keymap failure
retains the prior catalog (full's diagnostics are per-line).
